## Test-design.org - Practical Exercises

A set of manual tests for the Test Design Practical Exercises web application, covering the entire quality assurance lifecycle, from test planning to bug reporting.

Created to demonstrate real-world manual testing techniques: developing test cases using BVA and equivalence partitioning, structured bug reports with reproduction steps, and organized test execution records.

## Techniques used

- **Boundary Value Analysis (BVA)** — input field limits, quantity ranges
- **Equivalence Partitioning (EP)** — valid/invalid input classes
- **Decision Table Testing** — combinations of input values
- **Exploratory Testing** — input of invalid values, optimization of the number of checks
